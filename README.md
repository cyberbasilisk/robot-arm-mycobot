## Robot Arm (MyCobot 280 series)

A simulation environment for the Elephant Robotics myCobot 280 6-DOF desktop arm, built with ROS 2, Gazebo and RViz. Visualize, control and plan motions for the arm entirely on a PC, with no physical robot required.

### Features

1. URDF/xacro model of the myCobot 280 with visual and collision meshes.
2. One-command Gazebo launch that spawns the arm and starts the controllers.
3. RViz configuration showing the robot model, TF frames and joint states.
4. Joint trajectory control through standard ROS 2 topics and actions.
5. MoveIt-2 configuration for planning and execution in simulation.
6. Automated tests that launch the simulation and check its behavior.
